## 発見1 URLのパスの途中に年月がある

```
https://www-asia.nissan-cdn.net/content/dam/Nissan/jp/vehicles/note/2608/pdf/note_2608_specsheet.pdf
                                                              ~~~~          ~~~~
```

年月（2608 = 2026-08）が**パスとファイル名の2箇所**に出る。`spec_sources` の
`monthly` は「ベースパス＋YYYYMM＋.pdf」しか組み立てられないため使えない。
`fixed` で登録してある。

**月が変わるとURLが404になる。** `collect` は3回続けて失敗すると `last_error` に
印を付けて人間に上げるので、気づけないまま古い版を見続けることはない。
ただし再登録は手作業になる。年月をパスの途中に差し込める方式を足すなら、
`monthly` をテンプレート（`.../note/{YYMM}/pdf/note_{YYMM}_specsheet.pdf`）に
一般化するのが素直である。

## 発見2 諸元と装備が同じページの左右に並ぶ

ページが 1417pt（A3横より広い）あり、左に主要装備一覧、右に主要諸元、
さらに右にエンジン&モーター主要諸元が置かれている。
「ページ単位で諸元か装備かが決まる」という前提はトヨタでしか成り立たない。

## 発見3 装備の色が6種類ある

| 色 | 意味 | DBへの写像 |

| 水色 (192,224,240) | 標準装備 | `standard` |
| 紫 (192,160,208) | Black Edition専用装備 | `standard`（Black Edition の列だけ） |
| 黄 (240,240,176) | メーカーオプション | `option` |

トヨタは4種、スズキは3種だった。**色の数も意味もメーカーごとに違う。**

## 発見4 グレード名に駆動方式が入る

```
X（2WD）  X FOUR（4WD）
```

ホンダの `e:HEV X` と同じ形で、商品名に駆動方式が含まれる。
`name` に商品名を残し、`driveSystem` は別に持つ（ホンダと同じ扱いにする）。

Black Edition は独自の価格を持つ（X 2,399,100円 に対し X Black Edition
2,499,200円）ため、スズキのパッケージ装着車とは違い**別グレードとして扱う**。

## 発見5【重大】装備表が左右2ブロックに分かれている

1ページ目は「ラベル＋4列」の組が**左右に2つ**並ぶ。2ページ目は左が装備、右が諸元である。

```
page1  ラベル(x<412) 列(444.8/510.3/575.5/640.8) │ ラベル(760-1121) 列(1153.4/1219/1284/1349)
page2  ラベル(x<412) 列(444.8/510.3/575.5/640.8) │ 主要諸元
```

**最初は左のラベルと右の色を突き合わせてしまい**、「UVカットグリーンガラス〈フロント〉が
ディーラーオプション」のような明らかに誤った結果が出た。ラベルのx範囲と列のx範囲を
対にして扱う必要がある。1ブロックを前提にすると気づかないまま誤った値を書き込む。
