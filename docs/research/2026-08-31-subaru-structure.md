# スバルの諸元表・装備表の構造

- **日付**: 2026-08-31
- **対象**: スバル インプレッサ（`specifications.pdf` / `equipment.pdf`）
- **状態**: 構造の調査まで。**諸元の読み取り・価格・装備は未着手**

## 収集元

固定URLで、諸元・装備・環境仕様が別々のPDFに分かれている（ホンダと同じ形）。

```
https://www.subaru.jp/impreza/specification/docs/specifications.pdf   主要諸元（3ページ）
https://www.subaru.jp/impreza/specification/docs/equipment.pdf        主要装備
https://www.subaru.jp/impreza/specification/docs/ecology.pdf          環境仕様
```

`specifications.pdf` を `fixed` で登録済み。`collect` は通っており、PDFは保存されている。
`equipment.pdf` は未登録（車種につき2つ登録する運用はホンダで先送りにしたままである）。

## 発見1 括弧が2種類あり、意味が違う

```
車両重量  1540〈1550〉［1580〈1590〉］注2
          ~~~~         ~~~~
          FWDの素       AWDの素
              ~~~~~~          ~~~~~~
              FWDのオプション装着時  AWDのオプション装着時
```

- `［ ］` … **AWD**。表頭に `FWD［AWD（常時全輪駆動）］` と明記されている
- `〈 〉` … **オプション装着時**の値（注2に「〈 〉内は…装着した場合の車両重量」とある）

`［ ］` の意味はトヨタと同じだが、**同じ文書に別の意味の括弧が同居する点はスズキと同じ**である。
素の値（どちらの括弧にも入っていない値）を採る。

## 発見2 グレード7つが2つのエンジン群に分かれる

| 群 | グレード | 型式 | エンジン |
|---|---|---|---|
| 2.0L | ST / ST Smart Edition / ST Black Selection / ST Style Edition | 3BA-GU6［3BA-GU7］ | 2.0L DOHC 直噴 |
| e-BOXER | ST-G / ST-H / ST-H Style Edition | 5AA-GUD［5AA-GUE］ | 2.0L DOHC 直噴＋モーター |

全グレードが FWD と AWD の両方を持つため、展開すると**14グレード**になる。
変速機は全車リニアトロニック（CVT）。

型式は群ごとに1つで、**7グレードを2つの型式が覆う**（ホンダ・スズキと同じ）。

## 発見3 諸元の値は群ごと、一部はグレードごと

寸法は2群ぶんしか無いが、車両重量は3列（2.0L群 / ST-G / ST-H・ST-H Style）に分かれる。
**行によって列の粒度が違う**ので、行ごとに値の数を数える必要がある。

読み取り済みの値:

| | 2.0L群 | e-BOXER ST-G | e-BOXER ST-H系 |
|---|---|---|---|
| 全長×全幅×全高 | 4475×1780×1480 | 4475×1780×1515 | 4475×1780×1515 |
| ホイールベース | 2670 | 2670 | 2670 |
| トレッド 前/後 | 1540/1545 | 同じ | 同じ |
| 最低地上高 | 130 | 135 | 135 |
| 車両重量 FWD | 1390 | 1530 | 1540 |
| 車両重量 AWD | 1440 | 1570 | 1580 |
| 乗車定員 | 5 | 5 | 5 |
| 総排気量 | 1995 | 1995 | 1995 |

燃費は2行あり、どちらがWLTCかを確かめる必要がある。
モード別（市街地9.3［9.2］/ 郊外14.8［14.3］/ 高速17.1［16.5］）の平均から見て、
2.0L群は `14.0［13.6］` がWLTC、`15.8［14.7］` はJC08と思われる。**要確認。**

## 残っていること

2. 最高出力・最大トルクを読む
3. `equipment.pdf` を取得して装備の表現（記号か色か）を調べる
4. 価格の在り処を調べる（`https://www.subaru.jp/impreza/grade/`）
5. 取り込み用JSONを作る

DBには収集元の登録とPDFの保存までしか入れていない。grades は作っていない。
